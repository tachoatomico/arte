@tachoatomico editor ARTid

Editor de obras

Edita el metadata.json de cada obra. Al guardar, descarga o copia el JSON para commitearlo manualmente.

El editor no guarda en GitHub (sitio estático). Para aplicar el cambio:
1) Descargar/Copiar JSON · 2) reemplazá artworks/<id>/metadata.json · 3) hacé commit.
Para una obra nueva, además agregá su artwork_id al artworks/manifest.json.
